# 幣日子｜加密資產單人模擬交易

## 啟動

開啟 `index.html` 即可使用。每次開啟都會先顯示模擬聲明，按鈕倒數 3 秒後才能關閉。程式不需登入、交易帳戶或 API 金鑰。行情呼叫 Binance 官方文件標示的公開現貨市場資料端點；只讀行情，不呼叫帳戶、下單或資金端點。

## 行情來源與使用界線

- 第一個行情來源為 Binance Spot 公開市場資料 API：24 小時 ticker、最佳買賣價、委託簿及 K 線。交易所名稱只標示行情來源；遊戲沒有複製交易所帳戶或訂單系統。其他來源目前尚未接入。
- 每 30 秒更新；超過 90 秒的報價會被視為過期並停止交易。交易紀錄保留行情時間與來源識別。
- 官方文件：[Binance Spot REST API](https://developers.binance.com/en/docs/products/spot/rest-api)。公開 API 文件不等於資料再發布授權；公開展示前請確認來源條款。遊戲不打包散布行情資料檔，行情由使用者瀏覽器向來源端取得。
- 本程式沒有交易所商標圖像；來源文字只供辨識資料來源，並不表示 Binance 背書或隸屬。

## 模擬交易

- 新遊戲初始資金為 10,000 USDT，可模擬開多、開空及平倉；同一幣種同時只持有一個方向，須先平倉才可反向開倉。
- 市價單讀取最新委託簿最多 100 檔，依深度估算成交均價、滑價與手續費；深度不足時拒絕整筆交易。
- 限價委託保存在本機，觸價後按當時最佳買／賣報價是否達到限價來嘗試模擬成交；成交價採玩家輸入限價。它不模擬委託簿深度、排隊順位、部分成交或保證成交，可在「限價委託」頁取消。
- 1× 至 5× 槓桿、隔離保證金及多空損益均為教學模擬。維持保證金率、強平費及觸發方式是簡化假設，不代表交易所實際衍生品規則；現貨行情也不是實際衍生品標記價格。
- 費率預設 0.1%，可於遊戲設定調整。手續費不代表特定交易所費率。
- 僅作學習與娛樂，不涉及真實金錢、借幣、錢包或真實下單，也不構成投資建議。
- 開啟遊戲時會顯示免責提醒：所有遊戲交易及資產均為模擬，行情只作遊戲參考，可能延遲、不完整或不準確，模擬成交不代表實際市場成交。

## 資料保存

遊戲進度保存在 `localStorage`，限目前瀏覽器與裝置；不會自動跨裝置同步。另有保留舊版台股遊戲資料，不會覆蓋其儲存資料。

## 驗證

在此資料夾執行 `node --check app.js` 與 `node smoke-test.cjs`。測試以模擬 API 回應驗證現貨行情、多空記帳、限價觸發、委託簿市價成交、費用、損益、強平與開站提醒倒數。
